## 1. 디자인 철학 및 기본 원칙

1. **절제된 미니멀리즘 (Minimalist & Clean)**:
   - 과도한 이모티콘이나 화려한 그라데이션을 배제하고, 여백과 정돈된 타이포그래피로 전문성을 높입니다.
2. **높은 가독성 (Readability First)**:
   - 본문 텍스트는 선명하고 눈이 편안한 깊은 차콜 블랙(`#0d0d0d` / `#1a1a1a`)을 사용하며, 행간(Line-height: 1.75)과 자간을 넉넉히 확보합니다.
3. **일관된 레이아웃 구조 (Consistent Spatial Grid)**:
   - 메인 랜딩과 문서 뷰어가 동일한 헤더, 네비게이션, 폰트, 여백 시스템을 공유하여 사용자 경험의 일체감을 유지합니다.

## 3. 타이포그래피 스케일 (Typography)

- **기본 폰트 스택**: `-apple-system, BlinkMacSystemFont, "Pretendard", "Segoe UI", Roboto, Helvetica, Arial, sans-serif`
- **코드 폰트 스택**: `ui-monospace, SFMono-Regular, Menlo, Monaco, Consolas, monospace`

| 레벨 | 폰트 크기 | 굵기 | 여백 (Margin) | 설명 |
|---|---|---|---|---|
| **H1 (문서 제목)** | `2.1rem` (34px) | 800 (Bold) | `margin-bottom: 20px` | 문서 최상단 대표 제목, 하단 구분선 |
| **H2 (대주제)** | `1.5rem` (24px) | 700 (Bold) | `margin: 36px 0 14px` | 본문 섹션 구분, 하단 미세선 |
| **H3 (소주제)** | `1.2rem` (19px) | 600 (SemiBold) | `margin: 24px 0 10px` | 하위 상세 항목 |
| **Body (본문)** | `1.0rem` (16px) | 400 (Regular) | `line-height: 1.75` | 일반 문단 (단락 간격 16px) |
| **Caption/Meta** | `0.85rem` (13.6px) | 500 (Medium) | `line-height: 1.5` | 파일명, 날짜, 인용 출처 |

## 4. 컴포넌트 규격 표준

### 4.1 전체 레이아웃 (Layout Container)
- **최대 너비**: `max-width: 1400px; margin: 0 auto;`
- **구조**:
  - 좌측: 사이드바 (`width: 270px; flex-shrink: 0;`)
  - 중앙: 본문 뷰어 (`flex: 1; max-width: 820px; padding: 36px 48px;`)
  - 우측: 온페이지 목차 TOC (`width: 230px; flex-shrink: 0;`)

### 4.2 좌측 사이드바 (Sidebar)
- 배경: `#f9f9f9`, 우측 테두리: `1px solid #e5e5e5`
- 카테고리 헤더: `font-size: 0.75rem; font-weight: 700; color: #8e8e8e; text-transform: uppercase;`
- 링크 항목: `padding: 8px 12px; border-radius: 6px; font-size: 0.9rem;`
  - 활성(Active) 상태: `background: #ffffff; color: #0284c7; font-weight: 600; border: 1px solid #e5e5e5;`
- 접힘(Collapsed): `width: 0; opacity: 0;` 부드러운 애니메이션 전환

### 4.3 코드 블록 (Code Block)
- **인라인 코드**: `background: #f4f4f4; color: #0d0d0d; border: 1px solid #e5e5e5; padding: 2px 6px; border-radius: 4px;`
- **다중행 코드 블록**:
  - 배경: `#1e1e1e` (안정적인 다크 모드 블록으로 코드 시인성 극대화)
  - 헤더: 코드 블록 상단에 언어 라벨(Python, JS 등) 및 복사(Copy) 버튼 제공
  - 폰트 크기: `0.88rem`, 줄간격 `1.55`

### 4.4 인용문 / 알림 박스 (Callout)
- `border-left: 3px solid #0284c7; background: #f8fafc; border: 1px solid #e2e8f0; border-left-width: 3px; border-radius: 0 6px 6px 0;`

### 4.5 테이블 (Table)
- `border-collapse: collapse; width: 100%; font-size: 0.9rem;`
- 헤더(`th`): `background: #f9f9f9; color: #0d0d0d; font-weight: 600;`
- 교차 행: `tr:nth-child(even) { background: #fafafa; }`
