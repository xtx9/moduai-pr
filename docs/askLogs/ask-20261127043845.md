## 3. 원인 분석 및 보안 조치

1. **위험 요소**: 저장소 루트(`/`)를 그대로 웹 루트로 서비스할 경우, 루트에 위치한 `package.json`, `.clinerules`, `.env.example`, `AGENTS.md`, 그리고 무엇보다 내부 개발 이력인 `docs/ask.md`, `docs/todo.md`, `docs/askLogs/` 등이 브라우저 URL로 접근 가능해지는 보안 리스크가 발생함.
2. **해결 방안 (`public/` 분리)**:
   - `moduai-dev`와 동일한 방식으로 웹 전용 디렉터리 **`public/`**을 생성.
   - `index.html`, `docs.html`, `.nojekyll`, `assets/`, `content/` 등 웹 관련 파일을 `public/` 하위로 이동.
   - 소스 코드 헤더 주석을 `public/...` 경로로 수정.
3. **GitHub Pages 배포 방안 정비**:
   - GitHub Pages `Settings` → `Pages`에서 Source를 **`GitHub Actions` (Static HTML 템플릿)**로 지정하고, 업로드 경로를 **`path: './public'`**으로 설정하여 오직 `public/` 안의 파일만 웹으로 안전하게 배포되도록 가이드 마련.
