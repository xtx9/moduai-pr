## 4. 핵심 구현 기능

1. **Zero-Build 아키텍처**:
   - 복잡한 React/Vue 빌드 번들러 없이, 순수 브라우저 Fetch + CDN 파서를 활용하여 GitHub Pages 루트(`/`)에서 즉시 구동.
2. **동적 마크다운 파싱 & 코드 하이라이트 (`markdown-viewer.js`)**:
   - `marked.js`로 `.md` 문서를 HTML로 실시간 변환.
   - `highlight.js`와 `github-dark` 테마를 연동하여 코드 문법 강조 자동 적용.
   - 본문 내 `H2`, `H3` 태그를 분석하여 우측 온페이지 목차(TOC) 자동 생성.
   - 하단 이전 강의 / 다음 강의 버튼 자동 연결.
3. **그래프 및 다이어그램 렌더러 (`diagram-renderer.js`)**:
   - 마크다운 내 ```` ```mermaid ```` 블록을 감지하여 실시간 SVG 다이어그램으로 변환 (Flowchart, SequenceDiagram 지원).
4. **CSS 분리 모듈화**:
   - `style.css`: 최신 CSS 변수 기반 다크/네온 테크 스타일, 모바일 반응형 햄버거 메뉴.
   - `docs.css`: 강의 가독성에 최적화된 본문 패딩, 코드 블록 그림자, 인용구 alert 스타일.
5. **네비게이션 JSON 기반 확장성**:
   - `content/navigation.json`에 카테고리와 파일 경로만 추가하면 사이드바 메뉴가 자동으로 생성됨.
