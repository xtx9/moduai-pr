## 3. GitHub 웹 화면 설정 4단계 핵심 절차

1. **저장소 Pages 이동**: `https://github.com/xtx9/moduai-pr` → **Settings** → 좌측 **Pages**
2. **Build and deployment 설정**:
   - **Source**: 드롭다운에서 **`GitHub Actions`** 선택
   - 추천 템플릿 중 **`Static HTML`**의 **[Configure]** 버튼 클릭
   - 열린 YAML 편집창에서 `Upload artifact`의 `path: '.'`을 **`path: './public'`** 으로 수정
   - 우측 상단 **[Commit changes...]** 클릭 (저장소에 `.github/workflows/static.yml` 생성 및 자동 배포 트리거)
3. **Custom domain 등록**:
   - 다시 **Settings** → **Pages** 로 이동
   - **Custom domain**에 **`moduai-pr.smartflex.org`** 입력 후 **Save** 클릭
4. **검증 및 Enforce HTTPS 활성화**:
   - 초록색 체크표시 **`DNS check successful`** 확인
   - TLS 인증서 발급(약 3~10분) 완료 후 **`Enforce HTTPS`** 체크(V) 활성화
