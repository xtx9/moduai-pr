## 3. 핵심 수행 내역

### 1) 심볼(Symbol SVG) 적용
- 원본 `심볼.svg`를 `moduai-pr/public/assets/images/symbol.svg` 로 복사 배치.
- `index.html`, `docs.html` 파비콘(`<link rel="icon" type="image/svg+xml">`) 적용.
- 헤더의 브랜드 로고에 이모티콘(`⚡`) 대신 `<img src="assets/images/symbol.svg" class="brand-symbol">` 탑재.

### 2) 좌측 사이드바 접기/펼치기(토글) 기능 구현
- 헤더 좌측에 직관적인 사이드바 토글 버튼(`<button class="sidebar-toggle-btn">`) 추가.
- `markdown-viewer.js`에 `toggleSidebar()` 및 `localStorage` 기반 상태 저장(`moduai-sidebar-collapsed`) 탑재 (새로고침해도 상태 유지).
- `docs.css`에 `.docs-sidebar.collapsed` 상태(너비 0, 부드러운 애니메이션 축소, 본문 확장) 적용.
- 모바일 화면에서도 햄버거 토글 및 문서 클릭 시 자동 닫힘 연동.

### 3) 과도한 이모티콘 제거 및 깔끔한 테크 문서화
- `content/navigation.json` 카테고리 및 항목에서 이모티콘 전면 제거 (순수 텍스트 기반 네비게이션).
- 마크다운 콘텐츠(`01-overview.md`, `02-architecture.md`, `chapter-01.md`, `chapter-02.md`)에서 불필요한 장식 이모티콘 배제.
- `index.html` Hero 배지 및 Feature 카드에서 이모티콘 대신 미니멀한 SVG 테크 아이콘으로 교체.

### 4) ChatGPT 라이트 모드(ChatGPT Light Theme) 전면 개편
- **배경색**: 본문 화이트(`--bg-primary: #ffffff`), 사이드바 및 보조 영역 소프트 그레이(`--bg-secondary: #f9f9f9`), 테두리(`--border-color: #e5e5e5`).
- **텍스트**: 깊고 또렷한 차콜 블랙(`--text-main: #0d0d0d`), 본문 텍스트(`#262626`), 보조 텍스트(`#5d5d5d`).
- **버튼**: ChatGPT 시그니처 딥 차콜 버튼(`background: #0d0d0d; color: #fff;`).
- **인라인 코드 & 코드 블록**: 인라인 코드 `#f4f4f4` 배경, 다크 코드 블록 `#1e1e1e`, Highlight.js 테마 `github.min.css` 라이트 모드 연동.
- **다이어그램**: Mermaid.js 라이트 테마(`neutral`, 배경 `#ffffff`, 투명한 연결선) 적용.
