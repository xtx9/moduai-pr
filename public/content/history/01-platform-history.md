## 2026-11-27 — 공개 웹 영역과 배포 구조 정리

사이트에서 공개할 정적 파일을 `public/` 아래에 모으고, 웹 배포 영역과 저장소의 개발·운영 자료를 구분하는 구조를 정리했습니다.

## 2026-11-27 — GitHub Pages 및 커스텀 도메인 연결

GitHub Actions를 통한 정적 사이트 배포 흐름을 구성하고, `moduai-pr.smartflex.org` 도메인을 유지하도록 CNAME 설정을 반영했습니다. 관련 변경 기록에는 배포 재실행 및 라이브 응답 확인이 남아 있습니다.

## 2026-11-27 — 브랜드와 문서 뷰어 정비

moduai 심볼을 사이트 아이콘과 헤더에 적용하고, 밝은 테마와 미니멀한 화면 구성을 정리했습니다. 마크다운 문서 렌더링, 코드 표시 및 복사, 다이어그램, 본문 목차 등 문서 뷰어의 기반도 개선했습니다.

## 2026-11-27 — 문서 탐색과 사이드바 개선

문서 사이드바의 접기·펼치기, 화면 크기에 따른 동작, 모바일 오버레이와 키보드 조작을 개선했습니다.

## 2026-11-27 — 사업·개발 기록 중심으로 전환

기존 학습 자료 중심의 문서 탐색을 사업 소개, 개발 레퍼런스, 비전, 플랫폼 구축 히스토리 중심으로 재구성했습니다. 상단의 일반 메뉴와 저장소 바로가기 대신 개발 플랫폼으로 이동하는 단일 링크를 두는 방향으로 정리했습니다.
